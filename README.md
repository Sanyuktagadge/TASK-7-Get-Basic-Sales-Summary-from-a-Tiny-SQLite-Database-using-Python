# TASK-7-Get-Basic-Sales-Summary-from-a-Tiny-SQLite-Database-using-Python
# Simple Sales Data Analysis with Python & SQLite

This project demonstrates how to:
- Use SQL inside Python
- Analyze basic sales data
- Visualize results with bar charts
- Load .sql data into an SQLite database

---

## Objective

- Create a database using SQL script
- Query total quantity and revenue per product
- Show results in terminal (using `print`)
- Plot a bar chart of revenue by product



##  Technologies Used

- Python 3
- SQLite3
- Pandas
- Matplotlib
